# Job Application Tracker

A full-stack web application for tracking job applications, managing application statuses, and viewing application statistics through a dashboard.

## Features

* User authentication and account management
* Create, view, edit, and delete job applications
* Track application statuses
* Dashboard displaying application counts by status
* User-specific application data

## Tech Stack

* **Frontend:** Blazor, Bootstrap
* **Backend:** ASP.NET Core, C#
* **Database:** PostgreSQL
* **ORM:** Entity Framework Core
* **Authentication:** ASP.NET Core Identity

## Running Locally

1. Clone the repository.
2. Configure the PostgreSQL connection string using your local configuration.
3. Apply the Entity Framework Core database migrations.
4. Run the application using `dotnet run`.

See the project configuration for the required .NET version and database settings.

## Purpose

This project was built to practice full-stack application development, database integration, authentication, and CRUD operations using the .NET ecosystem.
